# Recall@50 corrected for pool depth

Generated by `depth50.py estimate`. The depth-20 pool leaves part of each system's top 50 unjudged, and those comments count as non-relevant in RESULTS_TABLES_comments.md. A random 150 of each system's unjudged top-50 comments (884 distinct pairs) were judged blind with the same guidelines. Sampled comments count at their real grade; only the unsampled remainder of each system's unjudged set is estimated, Horvitz-Thompson weighted by each comment's true inclusion probability (comments unjudged for several systems could be drawn by any of them). 95% intervals: bootstrap over queries, 2,000 resamples. Micro-averaged over 110 queries.
